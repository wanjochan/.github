# UGFT：术语与范围提示（避免歧义）

本目录所述 **UGFT（Unified Gauge Field Theory，统一规范场论）** 是一套**自定义/探索性**的统一规范场论叙述，与学术界另一个常用缩写 **TGFT（Tensorial Group Field Theory，张量化群场论）** 完全不是同一脉络。本页面用以把二者区分开，避免读者把本仓库的探索性叙述误当作主流 TGFT 文献结论。

## 1. 主流的 TGFT（Tensorial Group Field Theory）

在主流量子引力研究中，TGFT 指 Oriti、Rivasseau 等人推动的**张量化群场论**方向：场定义在群流形（如 SU(2)^d）上、与张量模型/Boulatov–Ooguri 作用量/spin foam 紧密相关，关注重整化群流、相变以及"时空涌现"等课题。本仓库**不**涉及这套形式体系。

## 2. 本目录文档中的 UGFT（本仓库用法）

本目录其它文件（如 `02-general-relativity.md`、`03-standard-model.md` 等）把 UGFT 用作一种**统一规范场论式**的组织方式，常见元素包括：

- 标架场 `e^a_μ`、自旋联络 `ω^{ab}_μ`
- 规范群结构 `PG(1,3) = SP(1,3) ⋊ W^{1,3}`（非齐次自旋规范群，含手征平移 `W^{1,3}` 承载引力）

这套叙述更接近 Poincaré 规范引力 / Einstein–Cartan / tetrad 形式的探索性"统一框架讲义"，与主流 TGFT 的标准定义**并不等价**。

## 3. 建议阅读方式

- 如果你的目标是**理解本仓库这套叙述内部的一致性**：从 `README.md` 的索引进入即可。
- 如果你的目标是**对齐主流 TGFT（Tensorial GFT）研究**：请以该方向的专门教材/论文为准，并将本目录内容视为独立的探索性文本。
